BOLIYAPUR COMMUNITY DIRECTORY

1) Open index.html in Chrome to preview the website.
2) To publish free: upload index.html and the images folder to a static hosting service such as GitHub Pages or Netlify.
3) Create these folders beside index.html if you want to add photos:
   images/gallery/
   images/schools/
   images/services/
4) Use the exact image filenames referenced in the code, or edit the image paths in the DATA object.
5) To add a new school/service/business, edit the DATA object near the bottom of index.html.
6) Important: some contact details came from the user-provided draft and are marked as needing verification. Confirm them before treating them as official.
