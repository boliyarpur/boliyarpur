# বলিয়াপুর কমিউনিটি ওয়েবসাইট — সহজ নির্দেশিকা

এই ওয়েবসাইটটি GitHub Pages-এ বিনামূল্যে চালানো যায়। কোডিং না জানলেও বেশিরভাগ লেখা, ছবি, ফোন নম্বর ও প্রতিষ্ঠানের তথ্য শুধু `data.js` ফাইলে বদলালেই হবে।

## ১) GitHub-এ নতুন করে আপলোড

1. ZIP ফাইল Extract করুন।
2. GitHub-এ নতুন Repository তৈরি করুন (Public রাখুন) অথবা আপনার পুরোনো Repository ব্যবহার করুন।
3. Extract করা ফোল্ডারের **ভেতরের সব ফাইল ও `images` ফোল্ডার** Repository-র মূল জায়গায় আপলোড করুন। ZIP ফাইলটি সরাসরি আপলোড করবেন না।
4. `index.html`, `style.css`, `app.js`, `data.js` এবং `images` ফোল্ডার একই স্তরে থাকবে।
5. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save নির্বাচন করুন।
6. কয়েক মিনিট পর GitHub Pages-এর দেওয়া লিংক খুলুন।

## ২) ছবি আপলোড করার নিয়ম

ছবির ধরন অনুযায়ী GitHub-এ এই ফোল্ডারগুলো ব্যবহার করুন:

- গ্রামের সাধারণ ছবি: `images/gallery/`
- স্কুল/অনুষ্ঠান/খবরের ছবি: `images/news/` অথবা `images/gallery/`
- প্রতিষ্ঠান/দোকানের ছবি: `images/services/`

GitHub-এ ফোল্ডারে ঢুকে Add file → Upload files → ছবি নির্বাচন → Commit changes করুন।

**খেয়াল রাখুন:** ছবির ফাইলের নাম ইংরেজিতে, ছোট হাতের অক্ষরে ও স্পেস ছাড়া দিন। যেমন `school-annual-program-2026.jpg`। ওয়েবসাইটে যে নাম লিখবেন, সেটি আপলোড করা ফাইলের নামের সঙ্গে হুবহু মিলতে হবে।

## ৩) ছবি, স্কুলের অনুষ্ঠান, খবর ও সেবা যোগ

GitHub-এ `data.js` খুলুন → Edit (পেন্সিল) → প্রয়োজনীয় অংশ বদলান → Commit changes।

### গ্যালারিতে ছবি যোগ
`gallery` তালিকার মধ্যে নতুন একটি item যোগ করুন:

```js
{
  title: "স্কুলের বার্ষিক অনুষ্ঠান",
  category: "স্কুলের অনুষ্ঠান",
  image: "images/gallery/school-annual-program-2026.jpg",
  date: "নভেম্বর ২০২৬"
}
```

### স্কুলের অনুষ্ঠান যোগ
`schools` তালিকায় যোগ করুন:

```js
{
  title: "বার্ষিক ক্রীড়া প্রতিযোগিতা",
  date: "নভেম্বর ২০২৬",
  description: "অনুষ্ঠানের সংক্ষিপ্ত বিবরণ লিখুন।",
  image: "images/news/sports-day.jpg",
  school: "স্কুলের নাম"
}
```

### স্থানীয় সেবা / স্কুল / হাসপাতাল / দোকান যোগ
`services` তালিকায় যোগ করুন:

```js
{
  name: "প্রতিষ্ঠানের নাম",
  category: "শিক্ষাপ্রতিষ্ঠান",
  description: "প্রতিষ্ঠানের পরিচিতি",
  phone: "01XXXXXXXXX",
  address: "বলিয়াপুর, সাভার, ঢাকা",
  image: "images/services/school.jpg",
  website: ""
}
```

Category হিসেবে ব্যবহার করতে পারেন: `স্বাস্থ্যসেবা`, `শিক্ষাপ্রতিষ্ঠান`, `স্থানীয় ব্যবসা`, `জরুরি সেবা`, `অন্যান্য`।

## ৪) অভিযোগ / মতামত WhatsApp-এ পাঠানো চালু

`data.js`-এর একদম উপরের দিকে এই লাইনটি খুঁজুন:

```js
whatsapp: "",
```

এখানে আপনার বা কমিউনিটি পরিচালকের WhatsApp নম্বর দেশের কোডসহ বসান। বাংলাদেশের নম্বরের ধরন:

```js
whatsapp: "8801XXXXXXXXX",
```

`X`-এর জায়গায় নিজের আসল নম্বর বসাবেন। `+`, স্পেস বা ড্যাশ দেবেন না। নম্বরটি সঠিক কি না পরীক্ষা করুন।

তারপর Commit changes দিন। এখন অভিযোগ ফর্ম পূরণ করলে WhatsApp খুলবে এবং লেখা বার্তা তৈরি হবে। ব্যবহারকারী WhatsApp-এ বার্তাটি দেখে নিজে Send করবেন।

**গুরুত্বপূর্ণ:** এই স্ট্যাটিক ওয়েবসাইট নিজে থেকে অভিযোগ ডেটাবেসে জমা রাখে না। WhatsApp-এ Send না করা পর্যন্ত বার্তা আপনার কাছে যাবে না। সম্পূর্ণ অনলাইন জমা, লগইন বা গোপন অ্যাডমিন প্যানেল চাইলে আলাদা backend/database লাগবে।

## ৫) ফোন, ইমেইল ও হোমের বড় ছবি

`data.js`-এ:
- `phone` = ফোন নম্বর (ঐচ্ছিক)
- `email` = যোগাযোগের ইমেইল (ঐচ্ছিক)
- `heroImage` = হোম পেজের বড় ছবির path

উদাহরণ:

```js
heroImage: "images/gallery/boliyapur-view.jpg",
phone: "01XXXXXXXXX",
email: "your-email@example.com",
```

## ৬) ছবি দেখা না গেলে

- ফাইলটি ঠিক ফোল্ডারে আছে কি না দেখুন।
- `data.js`-এ ছবির নাম ও extension (`.jpg`, `.jpeg`, `.png`, `.webp`) হুবহু মিলিয়ে নিন।
- Commit হয়েছে কি না নিশ্চিত করুন।
- ওয়েবসাইটে Ctrl + F5 চাপুন।

## গোপনীয়তা ও নিরাপত্তা

- অভিযোগে NID, ব্যাংক অ্যাকাউন্ট, পাসওয়ার্ড বা OTP চাইবেন না।
- শিশু বা অন্য কারও ছবি প্রকাশের আগে অভিভাবক/ব্যক্তির অনুমতি নিন।
- অভিযোগ বা ব্যক্তির নাম-পরিচয় প্রকাশের আগে যাচাই ও সম্মতি নিন।
- জরুরি বিপদে ওয়েবসাইটের অপেক্ষা না করে সরকারি জরুরি সেবায় যোগাযোগ করুন।
